# 1. Core SDR Concepts

## 1.1 SDR (Software-Defined Radio)

### Theory
**Software-Defined Radio (SDR)** implements radio functionality in software rather than dedicated hardware. Instead of fixed analog circuits for each protocol, SDR uses:
- **ADC/DAC** for analog-digital conversion
- **Digital signal processing** for modulation/demodulation
- **Software** for protocol implementation

### PlutoSDR Implementation
```
Traditional Radio:        PlutoSDR SDR:
┌──────────────┐         ┌──────────────┐
│  Fixed RF    │         │   AD9363     │
│  Circuitry   │         │  (Tunable)   │
│  (Hardware)  │         └──────┬───────┘
└──────────────┘                │
                                ▼
                         ┌──────────────┐
                         │  ADC/DAC     │
                         │  (12-bit)    │
                         └──────┬───────┘
                                │
                                ▼
                         ┌──────────────┐
                         │  Software    │
                         │  DSP/Demod   │
                         └──────────────┘
```

### LAB 1.1: Verify SDR Flexibility
**Objective:** Tune to different frequencies and protocols using the same hardware.

**Equipment:**
- PlutoSDR
- Python with pyadi-iio
- FM radio station (88-108 MHz)
- ISM band signal (433 MHz or 915 MHz)

**Code:**
```python
#!/usr/bin/env python3
"""
LAB 1.1: Demonstrate SDR flexibility by tuning to multiple bands
"""

import adi
import numpy as np
import matplotlib.pyplot as plt

def capture_spectrum(sdr, frequency, sample_rate, title):
    """Capture and plot spectrum at given frequency"""
    sdr.rx_lo = frequency
    sdr.sample_rate = sample_rate
    sdr.rx_buffer_size = 8192

    # Capture samples
    samples = sdr.rx()

    # Compute FFT
    fft = np.fft.fftshift(np.fft.fft(samples))
    freqs = np.fft.fftshift(np.fft.fftfreq(len(samples), 1/sample_rate))
    psd = 20 * np.log10(np.abs(fft) / len(fft))

    # Plot
    plt.figure(figsize=(10, 4))
    plt.plot(freqs/1e6, psd)
    plt.xlabel('Frequency Offset (MHz)')
    plt.ylabel('Power (dB)')
    plt.title(f'{title} - Center: {frequency/1e6:.1f} MHz')
    plt.grid(True)
    plt.savefig(f'lab1_1_{frequency}.png')
    plt.show()

# Connect to PlutoSDR
sdr = adi.Pluto("ip:192.168.2.1")
sdr.gain_control_mode_chan0 = "manual"
sdr.rx_hardwaregain_chan0 = 60

# Frequency hopping demonstration
frequencies = [
    (98.0e6, "FM Radio Band"),
    (433.0e6, "ISM Band 433 MHz"),
    (915.0e6, "ISM Band 915 MHz"),
    (2450.0e6, "WiFi/Bluetooth 2.4 GHz"),
]

for freq, desc in frequencies:
    print(f"\nTuning to {desc} ({freq/1e6:.1f} MHz)...")
    capture_spectrum(sdr, freq, 2.084e6, desc)
    input("Press Enter for next frequency...")

print("\n✓ LAB COMPLETE: Same hardware, multiple frequencies/protocols!")
```

## 1.2 RF Front-End

### Theory
The **RF Front-End** consists of analog components before digitization:
- **LNA (Low-Noise Amplifier)**: First-stage amplification
- **Mixer**: Frequency conversion (RF → IF or IF → Baseband)
- **Filters**: Select desired band, reject out-of-band interference
- **LO (Local Oscillator)**: Generated by PLL/VCO

### PlutoSDR RF Chain
```
RX Path:
Antenna → LNA → BPF → Mixer (RF→IF) → LPF → Mixer (IF→BB) → ADC
                         ↑                        ↑
                      RX_LO                    90° shift
                                            (I/Q generation)
```

## 1.3 Baseband and I/Q Samples

### Theory
**Baseband** is the low-frequency representation of the RF signal.

**I/Q (In-phase/Quadrature) Sampling:**
- Complex representation: `s(t) = I(t) + jQ(t)`
- **I**: In-phase component (0° reference)
- **Q**: Quadrature component (90° shifted)
- Allows representation of both amplitude AND phase
- Enables negative frequencies (distinguishes USB from LSB)

**Why I/Q?**
```
Real sampling: Can't distinguish +f from -f
I/Q sampling:  Can represent full complex spectrum

Real:  [----negative----][----positive----]
         (aliased)           (usable)

I/Q:   [----negative----]0[----positive----]
         (distinguishable)  (distinguishable)
```

### LAB 1.3: Generate and Visualize I/Q Samples
**Objective:** Create I/Q samples, understand complex baseband

**Code:**
```python
#!/usr/bin/env python3
"""
LAB 1.3: Understanding I/Q Samples
"""

import numpy as np
import matplotlib.pyplot as plt

# Parameters
fs = 2.084e6  # Sample rate (Hz)
f_offset = 100e3  # 100 kHz offset from center
duration = 0.001  # 1 ms
t = np.arange(0, duration, 1/fs)

# Generate complex tone at +100 kHz offset
i_samples = np.cos(2 * np.pi * f_offset * t)
q_samples = np.sin(2 * np.pi * f_offset * t)
complex_samples = i_samples + 1j * q_samples

# Also generate a tone at -100 kHz (complex conjugate)
complex_samples_neg = np.cos(2 * np.pi * (-f_offset) * t) + \
                      1j * np.sin(2 * np.pi * (-f_offset) * t)

# Plot time domain
fig, axes = plt.subplots(3, 2, figsize=(14, 10))

# I/Q time domain
axes[0, 0].plot(t[:100]*1e6, i_samples[:100], label='I')
axes[0, 0].plot(t[:100]*1e6, q_samples[:100], label='Q')
axes[0, 0].set_xlabel('Time (μs)')
axes[0, 0].set_ylabel('Amplitude')
axes[0, 0].set_title('I and Q Time Domain (+100 kHz tone)')
axes[0, 0].legend()
axes[0, 0].grid(True)

# Constellation (I vs Q)
axes[0, 1].plot(i_samples[:1000], q_samples[:1000], '.', alpha=0.1)
axes[0, 1].set_xlabel('I')
axes[0, 1].set_ylabel('Q')
axes[0, 1].set_title('Constellation Plot (I vs Q)')
axes[0, 1].axis('equal')
axes[0, 1].grid(True)

# FFT of positive frequency tone
fft_pos = np.fft.fftshift(np.fft.fft(complex_samples))
freqs = np.fft.fftshift(np.fft.fftfreq(len(complex_samples), 1/fs))
axes[1, 0].plot(freqs/1e3, 20*np.log10(np.abs(fft_pos)))
axes[1, 0].set_xlabel('Frequency (kHz)')
axes[1, 0].set_ylabel('Magnitude (dB)')
axes[1, 0].set_title('FFT of +100 kHz Tone')
axes[1, 0].grid(True)
axes[1, 0].axvline(100, color='r', linestyle='--', label='Expected peak')
axes[1, 0].legend()

# FFT of negative frequency tone
fft_neg = np.fft.fftshift(np.fft.fft(complex_samples_neg))
axes[1, 1].plot(freqs/1e3, 20*np.log10(np.abs(fft_neg)))
axes[1, 1].set_xlabel('Frequency (kHz)')
axes[1, 1].set_ylabel('Magnitude (dB)')
axes[1, 1].set_title('FFT of -100 kHz Tone')
axes[1, 1].grid(True)
axes[1, 1].axvline(-100, color='r', linestyle='--', label='Expected peak')
axes[1, 1].legend()

# Real-only signal (what happens without Q)
real_only = np.cos(2 * np.pi * f_offset * t)
fft_real = np.fft.fftshift(np.fft.fft(real_only))
axes[2, 0].plot(freqs/1e3, 20*np.log10(np.abs(fft_real)))
axes[2, 0].set_xlabel('Frequency (kHz)')
axes[2, 0].set_ylabel('Magnitude (dB)')
axes[2, 0].set_title('FFT of Real-Only Signal (I only, no Q)')
axes[2, 0].grid(True)
axes[2, 0].axvline(100, color='r', linestyle='--', label='+100 kHz')
axes[2, 0].axvline(-100, color='b', linestyle='--', label='-100 kHz (alias)')
axes[2, 0].legend()

# Phase evolution
phase = np.angle(complex_samples[:1000])
unwrapped_phase = np.unwrap(phase)
axes[2, 1].plot(t[:1000]*1e6, unwrapped_phase)
axes[2, 1].set_xlabel('Time (μs)')
axes[2, 1].set_ylabel('Phase (radians)')
axes[2, 1].set_title('Phase Evolution of Complex Signal')
axes[2, 1].grid(True)

plt.tight_layout()
plt.savefig('lab1_3_iq_samples.png')
plt.show()

print("✓ LAB COMPLETE: I/Q samples demonstrated")
print("Key observations:")
print("  1. I/Q together create complex signal")
print("  2. Complex signal distinguishes +/- frequencies")
print("  3. Real-only signal has mirror images")
print("  4. Phase continuously rotates (frequency)")
```

**Expected Results:**
- Positive frequency tone appears ONLY at +100 kHz
- Negative frequency tone appears ONLY at -100 kHz
- Real-only signal has symmetric spectrum (ambiguity)
- **Conclusion:** I/Q sampling provides full complex spectrum

## 1.4 Sample Rate and Bandwidth

### Theory
**Sample Rate (Fs):** Samples per second (MSPS = Mega-samples per second)

**Nyquist Theorem:** Must sample at `Fs ≥ 2 × BW` to avoid aliasing

**For complex I/Q sampling:**
- Usable bandwidth = Fs (not Fs/2)
- Can span from -Fs/2 to +Fs/2

**PlutoSDR Sample Rates:**
- Hardware: AD9363 can do up to 61.44 MSPS
- USB 2.0 limitation: ~6-8 MSPS sustained
- Practical range: 520 kSPS to 61.44 MSPS

### LAB 1.4: Nyquist Sampling and Aliasing
**Objective:** Demonstrate Nyquist theorem and aliasing

**Code:**
```python
#!/usr/bin/env python3
"""
LAB 1.4: Nyquist Sampling and Aliasing
"""

import adi
import numpy as np
import matplotlib.pyplot as plt

sdr = adi.Pluto("ip:192.168.2.1")

# We'll transmit a tone and receive it at different sample rates
sdr.tx_lo = 915e6
sdr.rx_lo = 915e6
sdr.tx_hardwaregain_chan0 = -30
sdr.gain_control_mode_chan0 = "manual"
sdr.rx_hardwaregain_chan0 = 50
sdr.tx_cyclic_buffer = True

# Generate a 500 kHz offset tone
fs_tx = 2.084e6
N = 16384
t = np.arange(N) / fs_tx
f_tone = 500e3  # 500 kHz offset
tx_samples = 0.5 * (np.cos(2*np.pi*f_tone*t) + 1j*np.sin(2*np.pi*f_tone*t))
tx_samples = (tx_samples * 2**14).astype(np.int16)  # Scale for DAC

# Transmit
sdr.tx(tx_samples)

# Test different RX sample rates
sample_rates = [1e6, 2.084e6, 4e6]  # 1, 2.084, 4 MSPS

fig, axes = plt.subplots(len(sample_rates), 1, figsize=(12, 10))

for i, fs_rx in enumerate(sample_rates):
    sdr.sample_rate = int(fs_rx)
    sdr.rx_buffer_size = 16384

    # Receive
    rx_samples = sdr.rx()

    # FFT
    fft = np.fft.fftshift(np.fft.fft(rx_samples))
    freqs = np.fft.fftshift(np.fft.fftfreq(len(rx_samples), 1/fs_rx))
    psd = 20 * np.log10(np.abs(fft) / len(fft))

    # Plot
    axes[i].plot(freqs/1e6, psd)
    axes[i].set_xlabel('Frequency Offset (MHz)')
    axes[i].set_ylabel('Power (dB)')
    axes[i].set_title(f'RX Sample Rate: {fs_rx/1e6:.3f} MSPS (BW = {fs_rx/1e6:.3f} MHz)')
    axes[i].grid(True)
    axes[i].axvline(0.5, color='r', linestyle='--', label='Expected tone (500 kHz)')

    # Mark Nyquist limits
    axes[i].axvline(-fs_rx/2e6, color='orange', linestyle=':', alpha=0.5, label='Nyquist limit')
    axes[i].axvline(fs_rx/2e6, color='orange', linestyle=':', alpha=0.5)
    axes[i].legend()

    # Check if tone is within Nyquist
    if f_tone <= fs_rx/2:
        status = "✓ No aliasing"
    else:
        status = "✗ ALIASING!"
        alias_freq = f_tone % (fs_rx/2)
        axes[i].axvline(alias_freq/1e6, color='orange', linestyle='--',
                       label=f'Aliased to {alias_freq/1e3:.0f} kHz')

    print(f"Fs={fs_rx/1e6:.3f} MSPS: {status}")

plt.tight_layout()
plt.savefig('lab1_4_nyquist.png')
plt.show()

sdr.tx_destroy_buffer()

print("\n✓ LAB COMPLETE: Nyquist theorem demonstrated")
print("Key points:")
print("  - Sample rate determines usable bandwidth")
print("  - Complex I/Q: BW = Fs (full)")
print("  - Undersampling causes aliasing")
```

**Expected Results:**
- At 1 MSPS: 500 kHz tone may alias (depends on decimation)
- At 2.084 MSPS: Tone visible at 500 kHz
- At 4 MSPS: Tone clearly visible with more spectrum
- **Conclusion:** Higher sample rate = wider observable bandwidth

## 1.5 Dynamic Range and SNR

### Theory
**Dynamic Range:** Difference between strongest and weakest detectable signal

**Components:**
- **Noise Floor:** Determined by thermal noise + NF
- **ADC Resolution:** PlutoSDR has 12-bit ADC → ~72 dB theoretical
- **Practical DR:** ~60-65 dB due to quantization, dithering

**SNR (Signal-to-Noise Ratio):**
```
SNR = Signal Power / Noise Power (in dB)
```

**Improving SNR:**
1. Increase gain (if not saturating)
2. Reduce bandwidth (less noise)
3. Averaging/filtering

### LAB 1.5: Measure Dynamic Range and SNR
**Objective:** Measure PlutoSDR noise floor and dynamic range

**Code:**
```python
#!/usr/bin/env python3
"""
LAB 1.5: Dynamic Range and SNR Measurement
"""

import adi
import numpy as np
import matplotlib.pyplot as plt

def measure_noise_floor(sdr, gain, bw):
    """Measure noise floor at given settings"""
    sdr.rx_hardwaregain_chan0 = gain
    sdr.rx_rf_bandwidth = int(bw)
    sdr.sample_rate = int(bw)
    sdr.rx_buffer_size = 16384

    # Capture
    samples = sdr.rx()

    # Compute noise power
    power = np.mean(np.abs(samples)**2)
    power_db = 10 * np.log10(power)

    # FFT for spectrum
    fft = np.fft.fftshift(np.fft.fft(samples))
    psd = 20 * np.log10(np.abs(fft) / len(fft))

    return power_db, psd

sdr = adi.Pluto("ip:192.168.2.1")
sdr.rx_lo = 915e6  # Use quiet frequency
sdr.gain_control_mode_chan0 = "manual"

# Test 1: Noise floor vs Gain
print("Test 1: Noise Floor vs Gain")
print("-" * 40)
gains = [0, 20, 40, 60, 73]
noise_floors = []

for gain in gains:
    nf, _ = measure_noise_floor(sdr, gain, 2.084e6)
    noise_floors.append(nf)
    print(f"Gain {gain:2d} dB → Noise Floor: {nf:6.2f} dB")

# Test 2: Noise floor vs Bandwidth
print("\nTest 2: Noise Floor vs Bandwidth")
print("-" * 40)
bandwidths = [200e3, 1e6, 2e6, 5e6, 10e6]
nf_bw = []

for bw in bandwidths:
    nf, _ = measure_noise_floor(sdr, 50, bw)
    nf_bw.append(nf)
    print(f"BW {bw/1e6:4.1f} MHz → Noise Floor: {nf:6.2f} dB")

# Test 3: Capture spectrum with and without signal
print("\nTest 3: SNR Measurement")
print("-" * 40)

# No signal (noise only)
sdr.rx_hardwaregain_chan0 = 50
sdr.sample_rate = 2.084e6
sdr.rx_rf_bandwidth = 2e6
noise_only = sdr.rx()

# With signal (connect antenna to FM radio or use TX loopback)
print("Connect antenna to receive a signal, then press Enter...")
input()

# Compute SNR
noise_power = np.mean(np.abs(noise_only)**2)
signal_power = np.mean(np.abs(signal_plus_noise)**2)
snr_db = 10 * np.log10(signal_power / noise_power)

print(f"Noise Power: {10*np.log10(noise_power):.2f} dB")
print(f"Signal+Noise Power: {10*np.log10(signal_power):.2f} dB")
print(f"SNR: {snr_db:.2f} dB")

# Plot
fig, axes = plt.subplots(2, 2, figsize=(14, 10))

# Noise floor vs gain
axes[0, 0].plot(gains, noise_floors, 'o-', linewidth=2, markersize=8)
axes[0, 0].set_xlabel('RX Gain (dB)')
axes[0, 0].set_ylabel('Noise Floor (dB)')
axes[0, 0].set_title('Noise Floor vs Gain')
axes[0, 0].grid(True)

# Noise floor vs bandwidth
axes[0, 1].semilogx([bw/1e6 for bw in bandwidths], nf_bw, 'o-', linewidth=2, markersize=8)
axes[0, 1].set_xlabel('Bandwidth (MHz)')
axes[0, 1].set_ylabel('Noise Floor (dB)')
axes[0, 1].set_title('Noise Floor vs Bandwidth')
axes[0, 1].grid(True)

# Spectrum comparison
fft_noise = np.fft.fftshift(np.fft.fft(noise_only))
fft_signal = np.fft.fftshift(np.fft.fft(signal_plus_noise))
freqs = np.fft.fftshift(np.fft.fftfreq(len(noise_only), 1/sdr.sample_rate))

axes[1, 0].plot(freqs/1e6, 20*np.log10(np.abs(fft_noise)), label='Noise only', alpha=0.7)
axes[1, 0].plot(freqs/1e6, 20*np.log10(np.abs(fft_signal)), label='Signal+Noise', alpha=0.7)
axes[1, 0].set_xlabel('Frequency (MHz)')
axes[1, 0].set_ylabel('Power (dB)')
axes[1, 0].set_title(f'Spectrum Comparison (SNR = {snr_db:.1f} dB)')
axes[1, 0].legend()
axes[1, 0].grid(True)

# Histogram of sample amplitudes
axes[1, 1].hist(np.abs(noise_only), bins=50, alpha=0.5, label='Noise', density=True)
axes[1, 1].hist(np.abs(signal_plus_noise), bins=50, alpha=0.5, label='Signal+Noise', density=True)
axes[1, 1].set_xlabel('Sample Amplitude')
axes[1, 1].set_ylabel('Probability Density')
axes[1, 1].set_title('Amplitude Distribution')
axes[1, 1].legend()
axes[1, 1].grid(True)

plt.tight_layout()
plt.savefig('lab1_5_dynamic_range.png')
plt.show()

print("\n✓ LAB COMPLETE: Dynamic range and SNR measured")
print("Key findings:")
print(f"  - Dynamic range: ~{noise_floors[-1] - noise_floors[0]:.0f} dB")
print(f"  - Noise increases with gain and bandwidth")

```

**Expected Results:**
- Noise floor increases with gain (more amplification)
- Noise floor increases with bandwidth (more noise integrated)
- Typical PlutoSDR dynamic range: 60-65 dB
- **Conclusion:** Trade-offs between gain, BW, and SNR

## 1.6 AGC (Automatic Gain Control)

### Theory
**AGC** automatically adjusts RX gain to maintain constant signal level.

**PlutoSDR AGC Modes:**
1. **Manual**: Fixed gain (user-controlled)
2. **Fast Attack**: Quick response to signal changes
3. **Slow Attack**: Gradual adaptation
4. **Hybrid**: Combination mode

**AGC Loop:**
```
Input Signal → Measure Power → Compare to Target →
Adjust Gain → Updated Signal → (repeat)
```

### LAB 1.6: AGC Performance
**Objective:** Compare manual vs automatic gain control

**Code:**
```python
#!/usr/bin/env python3
"""
LAB 1.6: AGC Performance Comparison
"""

import adi
import numpy as np
import matplotlib.pyplot as plt
import time

sdr = adi.Pluto("ip:192.168.2.1")
sdr.rx_lo = 915e6
sdr.sample_rate = 2.084e6
sdr.rx_buffer_size = 4096

# Test different AGC modes
agc_modes = ["manual", "fast_attack", "slow_attack"]
results = {}

for mode in agc_modes:
    print(f"\nTesting AGC mode: {mode}")
    sdr.gain_control_mode_chan0 = mode

    if mode == "manual":
        sdr.rx_hardwaregain_chan0 = 50

    # Capture multiple buffers to see adaptation
    powers = []
    gains = []

    for i in range(50):
        samples = sdr.rx()
        power = np.mean(np.abs(samples)**2)
        powers.append(10 * np.log10(power))

        # Try to read current gain (not always available in AGC mode)
        try:
            current_gain = sdr.rx_hardwaregain_chan0
            gains.append(current_gain)
        except:
            gains.append(None)

        time.sleep(0.01)

    results[mode] = {'powers': powers, 'gains': gains}
    print(f"  Mean power: {np.mean(powers):.2f} dB, Std: {np.std(powers):.2f} dB")

# Plot
fig, axes = plt.subplots(2, 1, figsize=(12, 8))

for mode, data in results.items():
    axes[0].plot(data['powers'], label=mode, linewidth=2, alpha=0.7)

axes[0].set_xlabel('Buffer Number')
axes[0].set_ylabel('Received Power (dB)')
axes[0].set_title('AGC Mode Comparison - Power Stability')
axes[0].legend()
axes[0].grid(True)

# Histogram of power levels
for mode, data in results.items():
    axes[1].hist(data['powers'], bins=30, alpha=0.5, label=mode, density=True)

axes[1].set_xlabel('Received Power (dB)')
axes[1].set_ylabel('Probability Density')
axes[1].set_title('Power Distribution by AGC Mode')
```

# 2. Digital Signal Processing (DSP)

## 2.1 Decimation and Interpolation

### Theory
**Decimation:** Reduce sample rate by factor M (downsample)
- Must filter first to avoid aliasing
- `Fs_out = Fs_in / M`

**Interpolation:** Increase sample rate by factor L (upsample)
- Insert zeros, then filter
- `Fs_out = Fs_in × L`

**PlutoSDR Implementation:**
- AD9363 has programmable FIR filters for decimation/interpolation
- Can configure via Filter Wizard or programmatically

### LAB 2.1: Decimation Example
**Objective:** Decimate a signal and observe effects

**Code:**
```python
#!/usr/bin/env python3
"""
LAB 2.1: Decimation and Interpolation
"""

import numpy as np
import matplotlib.pyplot as plt
from scipy import signal

# Generate test signal: sum of three sinusoids
fs = 10e6  # 10 MSPS
duration = 0.001  # 1 ms
t = np.arange(0, duration, 1/fs)

# Three frequency components
f1, f2, f3 = 100e3, 500e3, 1.5e6
sig = (np.sin(2*np.pi*f1*t) +
       np.sin(2*np.pi*f2*t) +
       np.sin(2*np.pi*f3*t))

# Add some noise
sig += 0.1 * np.random.randn(len(sig))

# Decimation by M=4 (10 MSPS → 2.5 MSPS)
M = 4

# Step 1: Low-pass filter (anti-aliasing)
# Cutoff at new Nyquist rate (fs/M/2 = 1.25 MHz)
nyquist = fs / 2
cutoff = (fs/M) / 2
sos = signal.butter(8, cutoff/(fs/2), 'low', output='sos')
sig_filtered = signal.sosfilt(sos, sig)

# Step 2: Downsample
sig_decimated = sig_filtered[::M]
fs_decimated = fs / M
t_decimated = np.arange(len(sig_decimated)) / fs_decimated

# Plot
fig, axes = plt.subplots(3, 2, figsize=(14, 10))

# Original signal time domain
axes[0, 0].plot(t[:1000]*1e6, sig[:1000])
axes[0, 0].set_xlabel('Time (μs)')
axes[0, 0].set_ylabel('Amplitude')
axes[0, 0].set_title(f'Original Signal (Fs={fs/1e6:.1f} MSPS)')
axes[0, 0].grid(True)

# Original spectrum
fft_orig = np.fft.fftshift(np.fft.fft(sig))
freqs_orig = np.fft.fftshift(np.fft.fftfreq(len(sig), 1/fs))
axes[0, 1].plot(freqs_orig/1e6, 20*np.log10(np.abs(fft_orig)))
axes[0, 1].set_xlabel('Frequency (MHz)')
axes[0, 1].set_ylabel('Magnitude (dB)')
axes[0, 1].set_title('Original Spectrum')
axes[0, 1].grid(True)
axes[0, 1].axvline(cutoff/1e6, color='r', linestyle='--', label=f'Filter cutoff')
axes[0, 1].legend()

# Filtered signal
axes[1, 0].plot(t[:1000]*1e6, sig_filtered[:1000])
axes[1, 0].set_xlabel('Time (μs)')
axes[1, 0].set_ylabel('Amplitude')
axes[1, 0].set_title('After Anti-Aliasing Filter')
axes[1, 0].grid(True)

# Filtered spectrum
fft_filt = np.fft.fftshift(np.fft.fft(sig_filtered))
axes[1, 1].plot(freqs_orig/1e6, 20*np.log10(np.abs(fft_filt)))
axes[1, 1].set_xlabel('Frequency (MHz)')
axes[1, 1].set_ylabel('Magnitude (dB)')
axes[1, 1].set_title('Filtered Spectrum')
axes[1, 1].grid(True)

# Decimated signal time domain
axes[2, 0].plot(t_decimated[:250]*1e6, sig_decimated[:250], 'o-')
axes[2, 0].set_xlabel('Time (μs)')
axes[2, 0].set_ylabel('Amplitude')
axes[2, 0].set_title(f'Decimated Signal (Fs={fs_decimated/1e6:.1f} MSPS, M={M})')
axes[2, 0].grid(True)

# Decimated spectrum
fft_dec = np.fft.fftshift(np.fft.fft(sig_decimated))
freqs_dec = np.fft.fftshift(np.fft.fftfreq(len(sig_decimated), 1/fs_decimated))
axes[2, 1].plot(freqs_dec/1e6, 20*np.log10(np.abs(fft_dec)))
axes[2, 1].set_xlabel('Frequency (MHz)')
axes[2, 1].set_ylabel('Magnitude (dB)')
axes[2, 1].set_title('Decimated Spectrum')
axes[2, 1].grid(True)

plt.tight_layout()
plt.savefig('lab2_1_decimation.png')
plt.show()

print("✓ LAB COMPLETE: Decimation demonstrated")
print(f"Original rate: {fs/1e6:.1f} MSPS → Decimated rate: {fs_decimated/1e6:.1f} MSPS")
print(f"Original samples: {len(sig)} → Decimated samples: {len(sig_decimated)}")
print("Note: 1.5 MHz component removed by anti-aliasing filter")
```

**Expected Results:**
- Original: 3 frequency peaks visible
- After filtering: High-frequency component (1.5 MHz) removed
- After decimation: Sample rate reduced, no aliasing
- **Conclusion:** Must filter before decimating

## 2.2 FIR and IIR Filters

### Theory
**FIR (Finite Impulse Response):**
- Output depends on finite number of past inputs
- Always stable
- Linear phase possible
- Used in PlutoSDR for decimation

**IIR (Infinite Impulse Response):**
- Output depends on past inputs AND outputs (recursive)
- More efficient (fewer taps for same performance)
- Phase nonlinearity
- Can be unstable if not designed carefully

### LAB 2.2: FIR vs IIR Filters
**Objective:** Design and compare FIR and IIR filters

**Code:**
```python
#!/usr/bin/env python3
"""
LAB 2.2: FIR vs IIR Filter Comparison
"""

import numpy as np
import matplotlib.pyplot as plt
from scipy import signal

fs = 2.084e6  # Sample rate

# Design specifications
cutoff = 200e3  # 200 kHz cutoff
transition_width = 50e3  # 50 kHz transition

# Design FIR filter (Parks-McClellan / Remez)
numtaps_fir = 101  # Number of taps
fir_coefs = signal.firwin(numtaps_fir, cutoff, fs=fs)

# Design IIR filter (Butterworth)
order_iir = 6
sos_iir = signal.butter(order_iir, cutoff, fs=fs, output='sos')

# Frequency response
w_fir, h_fir = signal.freqz(fir_coefs, worN=8192, fs=fs)
w_iir, h_iir = signal.sosfreqz(sos_iir, worN=8192, fs=fs)

# Group delay
_, gd_fir = signal.group_delay((fir_coefs, 1), w=8192, fs=fs)
_, gd_iir = signal.group_delay(signal.sos2tf(sos_iir), w=8192, fs=fs)

# Test signal: Chirp from 0 to 1 MHz
duration = 0.01
t = np.arange(0, duration, 1/fs)
test_signal = signal.chirp(t, 0, duration, 1e6)

# Filter the chirp
output_fir = signal.lfilter(fir_coefs, 1, test_signal)
output_iir = signal.sosfilt(sos_iir, test_signal)

# Plot
fig, axes = plt.subplots(3, 2, figsize=(14, 12))

# Magnitude response
axes[0, 0].plot(w_fir/1e6, 20*np.log10(abs(h_fir)), label='FIR', linewidth=2)
axes[0, 0].plot(w_iir/1e6, 20*np.log10(abs(h_iir)), label='IIR', linewidth=2, alpha=0.7)
axes[0, 0].set_xlabel('Frequency (MHz)')
axes[0, 0].set_ylabel('Magnitude (dB)')
axes[0, 0].set_title(f'Frequency Response (FIR: {numtaps_fir} taps, IIR: order {order_iir})')
axes[0, 0].axvline(cutoff/1e6, color='r', linestyle='--', alpha=0.5, label='Cutoff')
axes[0, 0].legend()
axes[0, 0].grid(True)
axes[0, 0].set_ylim([-80, 5])

# Phase response
axes[0, 1].plot(w_fir/1e6, np.unwrap(np.angle(h_fir)), label='FIR')
axes[0, 1].plot(w_iir/1e6, np.unwrap(np.angle(h_iir)), label='IIR')
axes[0, 1].set_xlabel('Frequency (MHz)')
axes[0, 1].set_ylabel('Phase (radians)')
axes[0, 1].set_title('Phase Response')
axes[0, 1].legend()
axes[0, 1].grid(True)

# Group delay
axes[1, 0].plot(np.linspace(0, fs/2, len(gd_fir))/1e6, gd_fir, label='FIR')
axes[1, 0].plot(np.linspace(0, fs/2, len(gd_iir))/1e6, gd_iir, label='IIR')
axes[1, 0].set_xlabel('Frequency (MHz)')
axes[1, 0].set_ylabel('Group Delay (samples)')
axes[1, 0].set_title('Group Delay (FIR = constant, IIR = varying)')
axes[1, 0].legend()
axes[1, 0].grid(True)
axes[1, 0].set_ylim([0, 200])

# Impulse response
axes[1, 1].stem(fir_coefs, label='FIR', linefmt='C0-', markerfmt='C0o', basefmt='C0-')
axes[1, 1].set_xlabel('Tap Index')
axes[1, 1].set_ylabel('Coefficient Value')
axes[1, 1].set_title(f'FIR Impulse Response ({numtaps_fir} taps)')
axes[1, 1].grid(True)

# Filtered output spectrogram
axes[2, 0].specgram(output_fir, NFFT=1024, Fs=fs, cmap='viridis')
axes[2, 0].set_xlabel('Time (s)')
axes[2, 0].set_ylabel('Frequency (Hz)')
axes[2, 0].set_title('FIR Output (Chirp filtered)')
axes[2, 0].set_ylim([0, 500e3])

axes[2, 1].specgram(output_iir, NFFT=1024, Fs=fs, cmap='viridis')
axes[2, 1].set_xlabel('Time (s)')
axes[2, 1].set_ylabel('Frequency (Hz)')
axes[2, 1].set_title('IIR Output (Chirp filtered)')
axes[2, 1].set_ylim([0, 500e3])

plt.tight_layout()
plt.savefig('lab2_2_fir_iir.png')
plt.show()

print("✓ LAB COMPLETE: FIR vs IIR comparison")
print(f"FIR: {numtaps_fir} taps, linear phase")
print(f"IIR: order {order_iir}, nonlinear phase, more efficient")
print("Chirp stops at cutoff frequency in both outputs")
```

**Expected Results:**
- FIR: Linear phase (constant group delay)
- IIR: Sharper rolloff, but nonlinear phase
- Both successfully low-pass filter the chirp
- **Conclusion:** FIR for phase accuracy, IIR for efficiency

## 2.3 FFT (Fast Fourier Transform)

### Theory
**FFT** converts time-domain signal to frequency-domain

**Key Concepts:**
- **DFT**: Discrete Fourier Transform (general algorithm)
- **FFT**: Fast implementation of DFT (O(N log N) complexity)
- **Frequency resolution**: `Δf = Fs / N` where N = FFT size
- **Zero-padding**: Interpolates spectrum (doesn't increase resolution)

**PlutoSDR Applications:**
- Spectrum analysis
- Channel estimation
- OFDM demodulation
- Frequency offset correction

### LAB 2.3: FFT Analysis and Windowing
**Objective:** Understand FFT, resolution, and window functions

**Code:**
```python
#!/usr/bin/env python3
"""
LAB 2.3: FFT Analysis with PlutoSDR
"""

import adi
import numpy as np
import matplotlib.pyplot as plt
from scipy import signal

sdr = adi.Pluto("ip:192.168.2.1")
sdr.rx_lo = 915e6
sdr.sample_rate = 2.084e6
sdr.gain_control_mode_chan0 = "manual"
sdr.rx_hardwaregain_chan0 = 60

# Capture samples
N = 16384
sdr.rx_buffer_size = N
samples = sdr.rx()

# Test different window functions
windows = {
    'Rectangular (no window)': np.ones(N),
    'Hann': np.hanning(N),
    'Hamming': np.hamming(N),
    'Blackman': np.blackman(N),
    'Kaiser (β=8)': np.kaiser(N, 8)
}

fig, axes = plt.subplots(3, 2, figsize=(14, 12))
axes = axes.flatten()

for idx, (name, window) in enumerate(windows.items()):
    # Apply window
    windowed = samples * window

    # FFT
    fft_result = np.fft.fftshift(np.fft.fft(windowed))
    freqs = np.fft.fftshift(np.fft.fftfreq(N, 1/sdr.sample_rate))
    psd = 20 * np.log10(np.abs(fft_result) / N)

    # Plot
    axes[idx].plot(freqs/1e6, psd, linewidth=1)
    axes[idx].set_xlabel('Frequency (MHz)')
    axes[idx].set_ylabel('Power (dB)')
    axes[idx].set_title(name)
    axes[idx].grid(True)
    axes[idx].set_ylim([-100, np.max(psd)+10])

    # Add frequency resolution annotation
    freq_resolution = sdr.sample_rate / N
    axes[idx].text(0.02, 0.98, f'Δf = {freq_resolution/1e3:.2f} kHz',
                   transform=axes[idx].transAxes,
                   verticalalignment='top',
                   bbox=dict(boxstyle='round', facecolor='wheat', alpha=0.5))

# Test FFT size effect
axes[5].clear()
fft_sizes = [1024, 4096, 16384]
for fft_size in fft_sizes:
    # Zero-pad or truncate
    if fft_size > len(samples):
        sig_padded = np.pad(samples, (0, fft_size - len(samples)))
    else:
        sig_padded = samples[:fft_size]

    fft_result = np.fft.fftshift(np.fft.fft(sig_padded))
    freqs = np.fft.fftshift(np.fft.fftfreq(fft_size, 1/sdr.sample_rate))
    psd = 20 * np.log10(np.abs(fft_result) / fft_size)

    axes[5].plot(freqs/1e6, psd, label=f'N={fft_size}', alpha=0.7)

axes[5].set_xlabel('Frequency (MHz)')
axes[5].set_ylabel('Power (dB)')
axes[5].set_title('FFT Size Comparison (zero-padding)')
axes[5].legend()
axes[5].grid(True)

plt.tight_layout()
plt.savefig('lab2_3_fft_windowing.png')
plt.show()

# Print statistics
print("✓ LAB COMPLETE: FFT and windowing")
print(f"\nFrequency resolution: {sdr.sample_rate/N/1e3:.2f} kHz")
print("\nWindow comparison:")
print("  - Rectangular: Narrowest main lobe, highest sidelobes (-13 dB)")
print("  - Hann: Good general purpose (-31 dB sidelobes)")
print("  - Hamming: Similar to Hann (-43 dB sidelobes)")
print("  - Blackman: Wider main lobe, lowest sidelobes (-58 dB)")
print("  - Kaiser: Adjustable trade-off (β parameter)")
```

**Expected Results:**
- Rectangular window: Spectral leakage visible (high sidelobes)
- Hann/Hamming: Reduced sidelobes, slight main lobe widening
- Blackman: Minimal sidelobes, widest main lobe
- Larger FFT: Better visual resolution (interpolation), not better frequency resolution
- **Conclusion:** Windows trade off frequency resolution vs sidelobe suppression
